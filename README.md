# إطار — منيوهات العملاء

محرّك واحد يخدم كل عملاء **إطار**. كل عميل = مجلد فيه ملف `menu.json` وصوره.

```
etar-menus/
├── engine/              ← الكود المشترك — عدّله مرة، يستفيد منه كل العملاء
│   ├── menu.css
│   └── menu.js
└── clients/
    └── oof-lounge/
        ├── index.html   ← ثابت لكل عميل، ما يتغيّر
        ├── menu.json    ← ⭐ الملف الوحيد الذي تعدّله
        └── img/         ← صور الأصناف (اختيارية)
```

---

## عميل جديد في ٣ خطوات

```bash
cp -r clients/oof-lounge clients/اسم-العميل
```
1. افتح `clients/اسم-العميل/menu.json` وعدّل `brand` والأقسام والأصناف
2. احذف `"draft": true` بعد اعتماد العميل للقائمة (يخفي الشريط الأحمر)
3. `git push` — الرابط يشتغل خلال دقيقة

---

## تعديل سعر أو صنف

كل شيء في `menu.json`. لا تفتح HTML ولا CSS.

```json
{ "ar": "لاتيه", "en": "Latte", "price": 25 }
```

- **تغيير سعر:** عدّل الرقم
- **إضافة صنف:** انسخ السطر وعدّله
- **وسم:** أضف `"tag": "best"` أو `"tag": "new"`
- **وصف:** أضف `"descAr"` و `"descEn"`
- **صورة:** ضع الملف في `img/` ثم `"img": "latte.webp"`

### إعدادات المحل (`brand`)

| المفتاح | المعنى |
|---|---|
| `ar` / `en` | اسم المحل بالعربي والإنجليزي |
| `theme` | `"dark"` (لاونجات ومقاهي مسائية) أو `"light"` |
| `color` / `color2` | اللون الأساسي والثانوي — تُطبَّق على كل الصفحة |
| `initial` | الحروف داخل دائرة الشعار |
| `whatsapp` | رقم **المحل** بالصيغة الدولية (زر الطلب السفلي) |
| `hoursAr` / `hoursEn` | أوقات العمل |

## التشغيل محلياً

```bash
cd ~/Desktop/etar-menus
python3 -m http.server 8010 --bind 127.0.0.1
```
ثم: `http://localhost:8010/clients/oof-lounge/`

> لازم سيرفر — فتح `index.html` مباشرة لا يعمل لأن المحرك يقرأ `menu.json` عبر `fetch`.

## الصور — قبل ما ترفعها

صورة الجوال ٣–٥ ميجا. ٤٠ صنفاً = منيو يفتح في ٢٠ ثانية والزبون يقفله.
**اضغط كل الصور قبل الرفع:**

```bash
# يحوّل كل الصور في المجلد إلى WebP بعرض 500 بكسل (~50 كيلوبايت للصورة)
cd clients/اسم-العميل/img
for f in *.jpg *.jpeg *.png; do
  [ -e "$f" ] || continue
  sips -Z 500 -s format jpeg -s formatOptions 78 "$f" --out "${f%.*}.webp" >/dev/null
done
```

**نصيحة:** لا تصوّر كل صنف. صوّر ١٠–١٥ صنفاً (الأعلى ربحاً) واترك الباقي بأيقونة القسم.

## ⚠️ قبل طباعة رمز QR

رمز QR **يتجمّد للأبد** على طاولات العميل. لا تطبع أي رمز قبل:

1. شراء الدومين النهائي
2. ربطه بالمستودع
3. التأكد أن الرابط النهائي يعمل

الرابط الحالي (`github.io`) **مؤقت للعرض فقط**.
